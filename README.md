# Calculator — CI/CD Laboratory Work

Учебный проект для практической работы № 2 по дисциплине «Технологии коллективной разработки информационных систем».

## Описание проекта

Простой калькулятор на Python, поддерживающий три арифметические операции:

- `add(a, b)` — сложение двух чисел.
- `subtract(a, b)` — вычитание двух чисел.
- `multiply(a, b)` — умножение двух чисел.

## Запуск тестов

Установить необходимые инструменты:

```bash
python -m pip install black pytest
```

Запустить тесты:

```bash
python -m pytest -q
```

Проверить форматирование кода:

```bash
python -m black --check .
```

## CI/CD

В проекте используется GitHub Actions.

Конфигурация находится в `.github/workflows/ci.yml`.

При отправке изменений в ветки `master`, `development` и `release`, а также при создании Pull Request в эти ветки, автоматически выполняются:

1. Загрузка исходного кода.
2. Установка Python 3.11 и зависимостей.
3. Проверка форматирования через Black.
4. Запуск автоматических тестов через pytest.
5. Генерация HTML-документации через pydoc.
6. Сохранение документации в GitHub Actions Artifacts.

## Ветки проекта

- `master` — основная ветка.
- `development` — разработка новых функций и исправлений.
- `release` — подготовка версий к выпуску.

## Документация

HTML-документация генерируется автоматически при выполнении CI.

Чтобы получить её, откройте вкладку **Actions** на GitHub, выберите успешный запуск workflow и скачайте артефакт `calculator-documentation`.

Локальная генерация документации:

```bash
python -m pydoc -w calculator
```
